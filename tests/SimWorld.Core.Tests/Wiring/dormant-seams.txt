# Dormant seams in src/SimWorld.Core — reviewed, and green on purpose.
#
# Every line names a seam nothing in src/ reaches, and says why that is acceptable today. The audit
# (tests/SimWorld.Core.Tests/Wiring/WiringAuditTests.cs) fails on any seam that is NOT on this list, and
# fails again on any line here that has since been wired up. So the file only ever shrinks, and a line
# disappearing is a system that started working.
#
# Format:  <check> <identity> | why it is dormant
#   interface       an interface with no implementation the game can ever hold
#   notify          a Notify_* hook nothing raises
#   worker          a Def field naming a placeholder, abstract or missing worker class
#   content-silent  code reads the field; every shipped Def leaves it null/false/zero/empty
#   code-deaf       shipped content sets the field; no line of src/ reads it
#   untouched       neither: no shipped Def moves it off the default and no line of src/ reads it
#   unwritten       code reads the state; nothing in src/ ever writes it
#
# Adding a line is a decision, not a formality. "Blocked on a module nobody has built" and "the host
# supplies it" are reasons; "the test was noisy" is not. If a check produces something you cannot explain,
# the check is wrong — fix or drop it rather than padding this file.

# ---- untouched: neither content nor code touches it ----
#
# The third field check, added after DifficultyDef.researchSpeedFactor turned out to be invisible to the
# other two: content-silent waits for code to read a field before it looks at the content, and code-deaf
# waits for content to set one before it looks at the code, so a field NEITHER side touches was reported
# by neither. It was found by a person reading the Def class, at the cost the audit exists to avoid.
#
# 48 entries at the measurement that decided this check shipped, out of 774 content fields surveyed.
# Sixteen are marked "Real gap" below: a knob somebody meant to matter, whose consumer could be written
# today against systems that already run. `grep "untouched.*Real gap"` is that to-do list, and it is the
# only part of this section anyone needs to read twice. The rest are RimWorld fields carried for parity
# whose consumer is a view, or whose system nobody has built.
#
# Four of these reasons were written after checking that an older one had expired — apparel, temperature,
# prisoners and the letter stack all exist now, and four declarations in src/ still say they do not. That
# is the §4 lesson (a recorded reason is evidence, not a verdict) arriving on schedule.
