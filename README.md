# simWorld

Colony-sim design project. Mechanics research on RimWorld, and a technical
spec/outline for a new game built on generalized versions of those systems.

- [`docs/research/rimworld-mechanics.md`](docs/research/rimworld-mechanics.md) —
  RimWorld systems reference: world/pawn generation, needs/mood, health,
  AI/jobs, storyteller/director, combat, crafting, economy, building,
  social/ideology, with diagrams per system.
- [`docs/spec/simworld-spec.md`](docs/spec/simworld-spec.md) — SimWorld
  technical spec: layered architecture, data model, core loop, and a module
  roadmap, with diagrams per layer.
